# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone.

## Our Standards

Examples of behavior that contribute to a positive environment include:

* Being respectful and considerate.
* Using welcoming and inclusive language.
* Accepting constructive feedback.
* Focusing on what is best for the project and its community.

Unacceptable behavior includes harassment, discrimination, personal attacks, and other inappropriate conduct.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the standards of this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces and interactions related to this project.

## Reporting

Instances of unacceptable behavior should be reported to the project maintainers.
